关于FastAPI

2026年6月17日星期三 阅读时长: 2 分钟

https://fastapi.tiangolo.com/

FastAPI 是一个基于 Python 类型注解构建的高性能 Web API 框架，用来快速开发后端服务（例如提供接口、部署模型、做前后端通信），特点是开发快、性能接近 Node.js/Go，并且自动生成 API 文档。
