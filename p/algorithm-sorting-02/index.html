8.1.1 树的定义和属性

通常将树T定义为存储一系列元素的有限节点集合，具有parent-children关系并且满足以下：

如果树T不为空，则它一定具有一个称为根节点的特殊节点，该节点没有父节点。

每个儿子都有一个爹，一个没孩子的节点称为外部节点，一个有一个或者多个孩子的节点称为内部节点。

树的一条边指的是一对节点（u，v），路径指的是一系列节点。

在一个python程序中，当使用单继承时，类与类之间的继承关系形成一棵树，所有类被组织成单一的层次结构，因为存在一个名为object的内置类作为最终的基类。

树的遍历算法

A /
B C / \
D E F

先序遍历：根->左->右

结果：A B D E C F，先序遍历常用于：复制一棵树、序列化二叉树、表达式树前缀表达式。

中序遍历：左 -> 根 -> 右

结果：D B E A C F，在 二叉搜索树 BST（满足左子树所有值<根节点值 < 右子树所有值） 里非常重要，bts的中序遍历结果一定是升序。

后序遍历：左->右- >根

结果：D E B F C A，后序遍历常用于：先处理子节点，再处理父节点 的场景。

广度优先遍历（BFS）：也叫层序遍历，从上到下，从左到右，一层一层访问。通常不用递归，用队列queue，队列的特点是先进先出。常用于求二叉树最小深度，找每一层最大值，找每一层平均值，判断完全二叉树，链接每一层的next指针。

结果：A B C D E F

二叉树的欧拉遍历：沿着树的边走一圈，每次进入节点，从左子树回来，从右子树回来，都可以记录一次。一个节点经过三次，统一先序，中序，后序。

结果：A B D D D B E E E B A C C F F F C A
